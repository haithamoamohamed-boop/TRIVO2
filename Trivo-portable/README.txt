Trivo portable app (with photos and videos)

On a computer: unzip and open index.html in Chrome, Edge or Safari. Keep the media folder next to it.

Installable on any phone or computer (free):
1. Upload ALL these files, including the media folder, to a public GitHub repository.
2. Settings > Pages > Deploy from a branch: main, / (root) > Save.
3. Open https://YOUR-NAME.github.io/REPO/ and install it (Android Chrome: menu > Install app; iPhone Safari: Share > Add to Home Screen; Chrome/Edge desktop: install icon in the address bar).

Inside Claude (sync, AI coach, calendar): attach this zip in a Claude chat and use the publish prompt from the Setup guide.
Your data stays in your own browser or Claude account; this package contains none.
