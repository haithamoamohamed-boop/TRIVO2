Trivo launcher: gives your full Trivo (inside Claude) its own icon.

1. Upload all files to a GitHub repository, e.g. "trivo-launcher".
2. Settings > Pages > Deploy from a branch: main, / (root) > Save.
3. Open https://YOUR-NAME.github.io/trivo-launcher/ on each device and install it (Android Chrome: menu > Install app; iPhone Safari: Share > Add to Home Screen; Chrome/Edge desktop: install icon in the address bar).
Tapping the icon opens your Trivo link. On iPhone you may need to sign in to Claude once inside it.
